## Overview

AnonVPN provides a simple way for Windows users to send network traffic through encrypted VPN connections. Version 18 emphasizes quick setup, dependable connectivity, and an uncluttered desktop interface where the primary controls remain readily available.

The client is intended for users who prefer a direct VPN experience without unnecessary complexity. Multiple server locations, automatic reconnect behavior, and a kill switch help maintain a consistent session while the application is designed to use modest system resources.

---

## Key Capabilities

- Connect to the VPN with one click
- Route traffic through encryption-focused VPN connections
- Use the kill switch to help prevent traffic from continuing after a connection loss
- Automatically reconnect during longer sessions when connectivity changes
- Choose between multiple available server locations
- Operate under a no-logs policy
- Keep desktop resource consumption low
- Switch to a dark-mode Windows interface

## Using AnonVPN

Start the application, pick a location, and press the main connect control. When using the client regularly, leaving it active in the background allows automatic reconnect and the kill switch to react to network interruptions or changes.

A normal connection sequence is:

1. Launch AnonVPN.
2. Choose one of the available server locations.
3. Select **Connect**.
4. Verify the displayed connection state before browsing or doing other network activity.
5. Choose **Disconnect** when the session is finished.
